# Estudio Perspectiva — Arq. Paulina Barba

Portafolio digital y sitio web oficial de la **Arq. Paulina Barba Martín (Estudio Perspectiva)**.

- **Especialidades:** Arquitectura residencial, interiorismo, dibujo ejecutivo y dirección de obra en Jalisco (Tepatitlán y Guadalajara).
- **Stack:** HTML5, Tailwind CSS, JavaScript nativo, diseño responsive de alto impacto y reproductor de audio integrado.
